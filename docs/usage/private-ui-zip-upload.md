# 私有 UI：上传 ZIP 扫描

登录私有 UI 后，选择“上传 ZIP 代码”，再选择源码压缩包即可开始白盒扫描。

- 仅接受 `.zip` 文件，单个文件最大 100 MB。
- ZIP 内路径不能是绝对路径、不能包含 `..`，也不接受符号链接。
- 解压后的源码总量最大 500 MB，文件数最大 20,000 个。
- 上传内容只在当前扫描期间保留；扫描结束、停止或失败后会自动删除源码压缩包和临时目录。
- 扫描报告仍按现有保留策略保存，可从“体检历史”下载 Markdown。

当前 ZIP 扫描使用 Runner 的本地代码模式。登录后扫描网站仍需要浏览器会话桥接；不要把网站密码或 Cookie 放进 ZIP 或扫描请求。
